# PROGRAM COUNTER

The program counter is a 16-bit register capable of incrementing and loading data synchronously. It is also able to asynchronously reset, which is good feature that will be used in the future when designing interruptions.
## Hardware ICs

It consists of 4 74161 4-bit binary counters, which paired up form the 16-bit register.
